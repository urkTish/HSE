Wireframes

Self-contained HTML (no external scripts, fonts or images). Each file opens with a note on what it decides and has an OS / Light / Dark switch that exercises tokens.css, which is inlined in every file.

  1. Country view with layer rail
    The application shell and the first screen: the map dominates, the layer rail doubles as the legend, and the first action is offered without a modal tour.
  2. Province view
    What a province is in this product: a context for exploring regions and cities, never a single verdict or a provincial average.
  3. City view with profile panel and climate chart
    The location profile structure and the climate-normals chart, including every provenance and anti-forecast rule.
  4. Comparison of two to four places
    How SPEC §4 ordinal bands, missing data, weights, essential gates and sensitivity are shown for two to four places.
  5. Search and concept search
    One search field that handles names (type-ahead) and concepts (criteria the user can see and edit).
  6. Mobile layout at 360 px
    The mobile layout at 360 px: full-bleed map, search pill, layers in a full-screen sheet, profile in a three-snap bottom sheet, comparison transposed.
