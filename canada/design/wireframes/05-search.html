Search and concept search

What this decides. One search field that handles names (type-ahead) and concepts (criteria the user can see and edit).

  • A: grouped suggestions (Places, Records, Search by idea), matched letters underlined in vermilion, full keyboard model (↑ ↓ Enter Esc), and a privacy line: search runs locally.
  • B: a concept query is shown back as explicit criteria chips, each naming the record category it uses and its threshold. Defaults are labelled "Our default" and are editable.
  • Criteria that need the user's own facts (budget) stay dashed and unapplied until set, so the system never guesses the user.
  • Results count criteria met with evidence; no data never counts as a match; a three-state mini-matrix (meets / does not meet / no data) shows why each place ranks where it does.
  • Phase 1 empty state is spelled out (no neighbourhood records yet) with a one-click way to widen the search.
