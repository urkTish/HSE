## Regressions and new side effects

- **R-1 · Minor · Clusters from different layers overlap.** Each layer
  clusters separately with `icon-allow-overlap`, so at Vancouver the
  climate cluster "3" is half hidden under the real-estate cluster "2" and a
  school diamond. Fix: give each layer's cluster a small fixed offset
  (`circle-translate` / `icon-offset` by layer index), or sort them with
  `symbol-sort-key` and let collisions hide the lower-priority one; a
  combined cluster with per-layer counts can wait for Phase 2.
- **R-2 · Minor · Dark-mode city marker read as a bullseye** (light fill,
  dark stroke, light halo), which is easy to confuse with the climate
  ring-dot. **Cause: my token value**, not Agent 05's code. Fixed here:
  dark `--ce-marker-halo` changed from `#ece9e2` to `#0f0f0d` (value only,
  logged in design-system §13). Rebuilt and checked: cities now read as solid
  discs. Agent 05 only needs to rebuild.
- **R-3 · Minor · Attribution runs behind the profile panel at 1440 px**
  and is cut off ("…Data from O"). Licence text must stay visible. Fix: when
  the panel is open, set the attribution's right margin to the panel width,
  or move it bottom-left beside the layer panel.
- **R-4 · Minor · Mobile gained a third top bar** ("Places in view"). This is
  part of F-04 (see above).
