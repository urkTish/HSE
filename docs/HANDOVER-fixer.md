# HSE platform: handover for the fixer agent

Written 2026-10-09. The repository is urkTish/HSE, branch `claude/hse-platform-build-kannxy` (there is no main branch and no PR).
The client is an HSE Manager on construction and airport projects in Saudi Arabia, and the whole platform is bilingual (English and Arabic, with right-to-left layout).

## 1. What the platform is

- **Backend:** `backend/`, built with Python 3.12, uv, FastAPI, SQLAlchemy 2, Alembic and Postgres 16. Tests use pytest, ruff and mypy in strict mode.
- **Frontend:** `frontend/`, built with Next.js App Router, strict TypeScript, Tailwind, shadcn, TanStack Query and next-intl. Browser tests use Playwright against the real backend.
- **API contract:** the API is defined contract-first in `docs/contracts/openapi.yaml`. It is generated by `uv run python -m app.export_openapi`, and CI checks that it is current with `--check`. The current version is 0.11.0 (environmental, in progress).
- **Docs:**
  - `docs/PROGRESS.md` holds current state, parked items, open questions, contract requests and design proposals.
  - `docs/DECISIONS.md` holds numbered decisions D-1 to about D-190. Check the highest number before adding one.
  - `docs/CONVENTIONS.md` holds the pinned integration rules: the error envelope `{"detail":{"code","message","message_ar"}}`, lists shaped as `{items,total,page,page_size}`, the httpOnly cookie `hse_session`, and QR codes in the form `HSE2:<kind>:<token>`.
  - `docs/specs/*.md` holds one spec per module.
  - `docs/design/phase-*-findings.md` holds the design findings.
- **Demo data:** `app.seed` loads every per-module seed: `seed_access`, `seed_med`, `seed_heat`, `seed_emergency`, `seed_field`, and next `seed_env`.
- **Test clock:** browser tests use a fixed clock, `HSE_CLOCK_AT=2026-10-06 10:00` Riyadh time. It is set in `frontend/e2e/clock.ts`, `e2e/fixtures/test.ts` and `e2e/start-backend.sh`.
- **Screenshots:** they are written only when `SCREENSHOTS=1` is set.
- **Local environment:** Postgres runs locally with user and password `hse`/`hse` and databases `hse` and `hse_test`. If it is down, start it with `pg_ctlcluster 16 main start`. There is no Docker.

## 4. Rules (from the HSE Manager)

- Don't waste time or usage. Fix root causes, and stop after one reasonable attempt on anything flaky; record it in PROGRESS instead of looping.
- Never skip, disable or quarantine a test to get green. Fix the cause or report it.
- Other agents work in the same working tree. Never `git add -A`; stage only your own files. Re-read PROGRESS.md and DECISIONS.md right before a small edit. If a push is rejected, run `git pull --rebase` and push again.
- Do not leave `app.seed` importing a module that doesn't exist yet. This has already broken other agents' e2e runs.
